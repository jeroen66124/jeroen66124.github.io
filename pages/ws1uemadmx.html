3 · Instructions & output

Profile creation:
Go to Resources › Profiles & Baselines › Profiles › Add › Add Profile › Windows › Desktop › Device Profile › Custom Settings › Configure › Set Target to OMA DM Client › enable Make Commands Atomic

Profile formatting:
For both profiles - copy the Install Settings and Remove Settings XML into the corresponding fields in the 'Custom Settings' payload.
Optionally, copy the example Profile name into the Name field under General.

Deployment order:
When publishing - add the 'Install Policies' profile before adding the 'Configure Policies' profile
When retiring - remove the 'Configure Policies' profile before removing the 'Install Policies' profile
