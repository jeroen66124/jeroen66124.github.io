Import into Workspace ONE UEM:
Go to Resources › Profiles & Baselines › Profiles › Add › Add Profile › Windows › Desktop › Device Profile › Custom Settings › Configure › Set Target to OMA DM Client › enable Make Commands Atomic

Profile formatting:
Paste the matching Install XML into Install Settings and Remove XML into Remove Settings for both profiles

XML content 1a + 1b = Profile 1 (Import)
AND
XML content 2a + 2b = Profile 2 (Configure)

Deployment order:
When publishing, add the Import Policies profile before adding the Configure Policies profile
When removing, remove the Configure Policies profile before removing the Import Policies profile
