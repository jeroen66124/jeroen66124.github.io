Profile creation:
Go to Resources › Profiles & Baselines › Profiles › Add › Add Profile › Windows › Desktop › Device Profile › Custom Settings › Configure › Set Target to OMA DM Client › enable Make Commands Atomic

Profile formatting:
For both profiles - copy the Install Settings and Remove Settings XML content below into their corresponding input fields in the 'Custom Settings' configuration screen

Deployment order:
When publishing - add the 'Import Policies' profile before adding the 'Configure Policies' profile
When retiring - remove the 'Configure Policies' profile before removing the 'Import Policies' profile
